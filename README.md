# 📋 Professional Task Manager (CLI)

A clean, lightweight, and professional Command Line Interface (CLI) application built with Python. This tool allows users to manage their daily tasks efficiently using a JSON-based database for persistent data storage.

---

## ✨ Features

- **Add Tasks:** Quickly add new tasks to your to-do list.
- **View Tasks:** Beautifully formatted display of all current tasks.
- **Delete Tasks:** Remove completed or unwanted tasks by ID.
- **Data Persistence:** Uses `json` module to save tasks, meaning your data remains intact even after closing the program.
- **Error Handling:** Prevents crashes from invalid user inputs.

---

## 🛠️ Technologies Used

- **Python 3.x**
- **JSON:** Core Python module for data storage.
- **OS:** Core Python module for file path checking.
